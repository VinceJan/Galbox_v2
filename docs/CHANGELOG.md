# Galbox 更新日志

本文档记录 Galbox 的版本历史和变更内容。

## 版本格式

版本号遵循语义化版本规范 (Semantic Versioning):

- `MAJOR`: 重大架构变更
- `MINOR`: 新增功能
- `PATCH`: Bug 修复和小改进

---

## [1.0.0-beta] - 2026-04-13

首个公开测试版本，包含核心功能实现。

### 新增功能

#### 核心功能

- **游戏库管理**
  - 自动扫描游戏文件夹
  - 手动添加单个游戏
  - 多引擎自动识别（Ren'Py、Kirikiri、Unity、RPG Maker、TyranoBuilder、VNM）
  - 游戏收藏标记
  - 游戏信息编辑

- **元数据刮削**
  - Bangumi API 集成（中文数据源）
  - VNDB Kana API 集成（国际数据源）
  - ymgal/cngal 占位实现（待完善）
  - 智能 Levenshtein 匹配算法
  - 90% 匹配阈值自动接受
  - 双层缓存机制（内存 + 数据库）
  - 多数据源并行搜索

- **存档管理**
  - 自动检测存档位置（支持 6 种引擎）
  - 一键备份存档（ZIP 格式）
  - 存档恢复功能
  - 存档槽位快速切换
  - 存档元数据提取
  - 备份数量上限管理

- **错误检测**
  - 中文路径问题检测
  - 日语区域设置需求检测
  - DirectX 组件缺失检测
  - K-Lite 解码器检测
  - Windows 兼容性问题检测
  - Visual C++ 运行库检测
  - 权限问题检测
  - 杀毒软件拦截提示
  - 错误历史记录

- **进程监控**
  - 游戏进程状态监控
  - Boss Key 快速隐藏（默认 Alt+Shift+H）
  - 自动截图功能（可选）
  - CPU/内存监控（可选）

- **用户界面**
  - WinUI 3 现代化界面
  - Mica 背景效果
  - NavigationView 导航框架
  - 游戏库网格/列表视图
  - 游戏详情页
  - 存档管理页
  - 补丁中心页（占位）
  - 设置页面

#### 设置功能

- 刮削数据源配置
- Bangumi OAuth 登录支持
- 启动/退出行为配置
- Boss Key 自定义
- 存档自动备份配置
- 进程监控配置
- 外观主题设置
- 语言设置（中文/英文/日文）

#### 数据存储

- SQLite 本地数据库
- Entity Framework Core ORM
- 游戏信息持久化
- 用户设置持久化
- 错误记录持久化

### 技术实现

- MVVM 架构模式（CommunityToolkit.Mvvm）
- 依赖注入（Microsoft.Extensions.DependencyInjection）
- 日志系统（Microsoft.Extensions.Logging）
- 异步 API 设计
- 速率限制保护
- 线程安全缓存

### 已知问题

#### 功能限制

1. **补丁中心**
   - 补丁 API 尚未完全实现
   - moyu.moe 补丁查询待集成
   - 补丁下载功能待开发

2. **刮削源**
   - ymgal API 结构待研究
   - cngal API 结构待研究
   - 部分冷门游戏可能匹配失败

3. **存档管理**
   - 自定义存档路径不支持
   - 部分引擎存档检测不准确
   - Registry 存档（PlayerPrefs）不支持

4. **错误检测**
   - 自动修复功能有限
   - 某些错误只能手动解决

#### UI/UX 问题

1. **界面优化**
   - 大量游戏时加载性能待优化
   - 搜索功能待完善
   - 批量操作 UI 待开发

2. **本地化**
   - 英文界面翻译不完整
   - 日文界面翻译待完成

#### 技术问题

1. **性能**
   - 大型游戏库加载时间较长
   - 扫描全盘时资源占用较高

2. **兼容性**
   - 部分 Windows 10 版本可能有显示问题
   - ARM64 设备未测试
