# Galbox 用户手册

欢迎使用 Galbox！本手册将帮助您快速了解和掌握 Galbox 的各项功能。

## 软件概述

Galbox 是一款专为 Galgame（视觉小说）玩家设计的游戏管理工具，提供以下核心功能：

- **游戏库管理** - 自动扫描、识别和管理多引擎 Galgame
- **元数据刮削** - 从 Bangumi、VNDB 等数据源获取游戏信息
- **存档管理** - 自动检测存档位置，支持备份、恢复和多版本管理
- **补丁中心** - 一键下载安装汉化补丁和修复补丁
- **快捷启动** - 快速启动游戏，支持老板键快速隐藏
- **截图管理** - 自动或手动截图，记录精彩瞬间

## 主界面介绍

Galbox 采用现代化的 WinUI 3 界面设计，主要分为以下几个区域：

### 导航栏

左侧导航栏包含以下主要模块：

| 模块 | 图标 | 功能 |
|------|------|------|
| **首页 (Home)** | 🏠 | 快速启动、最近游玩、收藏游戏 |
| **游戏库 (Library)** | 📚 | 所有游戏列表、搜索、筛选 |
| **存档管理 (Save Manager)** | 💾 | 存档备份、恢复、切换 |
| **补丁中心 (Patch Center)** | ⬇️ | 汉化补丁、修复补丁管理 |
| **设置 (Settings)** | ⚙️ | 应用配置、账户管理 |

### 首页布局

首页展示以下内容：

1. **快速启动卡片** - 显示最近游玩或收藏的游戏，一键启动
2. **正在游玩** - 最近 7 天内有游玩记录的游戏
3. **收藏游戏** - 用户标记为收藏的游戏
4. **最近游玩** - 按最后游玩时间排序的游戏列表

### 标题栏

- 显示应用名称 "Galbox"
- 支持 Mica 背景效果（跟随系统主题）
- 标题栏拖动可移动窗口

## 游戏库功能

游戏库是 Galbox 的核心模块，用于管理和浏览所有已添加的游戏。

### 视图模式

游戏库支持两种视图模式，可通过页面右上角的视图切换按钮切换：

| 视图模式 | 说明 |
|----------|------|
| **网格视图** | 以卡片形式展示游戏，显示封面、名称和评分，适合快速浏览 |
| **列表视图** | 以表格形式展示游戏，显示详细信息列，适合精确筛选 |

### 搜索功能

在页面顶部的搜索框中输入关键词，支持以下搜索条件：

- 游戏名称（中文/原名）
- 开发商名称
- 游戏标签

**搜索技巧：**
- 输入游戏名称的任意部分即可匹配
- 支持模糊搜索，无需完整输入
- 搜索结果实时更新

### 筛选功能

点击搜索框旁边的筛选按钮，打开筛选面板：

| 筛选条件 | 说明 |
|----------|------|
| **游戏状态** | 已安装、未安装、游玩中、已完成 |
| **标签/类型** | 按游戏类型筛选（恋爱、悬疑、奇幻等） |
| **评分范围** | 按评分区间筛选 |
| **添加时间** | 最近添加、本月添加 |
| **游玩状态** | 已游玩、未游玩 |
| **收藏状态** | 已收藏、未收藏 |

**组合筛选：**
- 多个筛选条件可同时生效
- 点击"重置"按钮清除所有筛选条件

### 排序功能

点击列标题或排序按钮，支持按以下方式排序：

- 名称（A-Z / Z-A）
- 添加时间（最新/最早）
- 最后游玩时间
- 评分（高到低 / 低到高）
- 游玩时长

### 批量操作

在列表视图下，可进行批量操作：

1. 勾选多个游戏（点击行首的复选框）
2. 选择批量操作：
   - **批量刮削** - 一次性获取多个游戏的元数据
   - **批量删除** - 从游戏库移除多个游戏
   - **批量添加标签** - 为多个游戏添加相同标签

## 游戏详情页

点击游戏卡片或列表行，进入游戏详情页。详情页展示游戏的完整信息和操作入口。

### 详情页布局

详情页分为以下几个区域：

#### 封面与基本信息

页面顶部展示：
- **游戏封面** - 大尺寸封面图片
- **游戏名称** - 中文名称和原名
- **评分** - 来自数据源的评分
- **开发商** - 游戏开发商
- **发布日期** - 原版发布日期
- **游玩状态** - 当前游玩进度状态

#### 游戏简介

封面下方展示游戏简介，支持：
- 展开/收起长文本
- 点击查看完整介绍

#### 标签区域

显示游戏标签，包括：
- 类型标签（恋爱、悬疑、奇幻等）
- 风格标签（校园、科幻、治愈等）
- 点击标签可筛选同类游戏

#### 角色列表

展示游戏主要角色信息：
- 角色头像
- 角色名称
- 声优信息（如有）
- 点击角色查看详情

### 功能操作区

详情页右侧或底部提供操作按钮：

| 功能按钮 | 说明 |
|----------|------|
| **启动游戏** | 一键启动游戏程序 |
| **打开目录** | 打开游戏安装目录 |
| **刮削** | 重新获取/更新游戏信息 |
| **存档管理** | 进入存档备份恢复界面 |
| **补丁管理** | 查看和安装可用补丁 |
| **收藏** | 添加到收藏列表 |
| **编辑** | 手动编辑游戏信息 |
| **删除** | 从游戏库移除游戏 |

### 启动设置

点击"启动游戏"旁的下拉箭头，可设置：

- **启动参数** - 自定义游戏启动参数
- **兼容性模式** - 设置管理员权限运行
- **转区设置** - 配置日语区域转区启动

### 游玩记录

页面底部显示游玩统计：

- **总游玩时长** - 累计游戏时间
- **最后游玩** - 最后一次启动时间
- **启动次数** - 总启动次数
- **截图数量** - 保存的截图数量

### 截图画廊

如果游戏有截图，将在详情页展示缩略图画廊：

- 查看所有游戏截图
- 点击查看大图
- 支持删除和管理截图

## 游戏添加流程

### 自动扫描添加

1. 进入 **游戏库 (Library)** 页面
2. 点击 **添加游戏 (Add Game)** 按钮
3. 选择 **扫描文件夹 (Scan Folder)** 选项
4. 选择包含游戏的根目录
5. 系统将自动扫描识别游戏可执行文件

**支持的自动识别引擎:**

- Ren'Py (`.rpy`, `python` 可执行文件)
- Kirikiri (`.xp3` 包文件)
- TyranoBuilder (`tyrano` 目录)
- Unity (`UnityPlayer.dll`, `_Data` 目录)
- RPG Maker (`rpg_core.js`, `.rvdata2`)
- 其他通用引擎

### 手动添加游戏

1. 在游戏库页面点击 **添加游戏**
2. 选择 **手动添加 (Manual Add)** 选项
3. 填写以下信息：
   - **游戏路径**: 游戏安装目录
   - **主可执行文件**: 启动游戏的主程序
   - **游戏名称**: 显示名称（可选，刮削后自动填充）

4. 点击 **确认 (Confirm)** 完成

### 批量添加

支持选择多个文件夹批量扫描添加游戏，系统会自动：
- 识别每个文件夹中的游戏
- 尝试自动刮削元数据（可配置）
- 建立游戏库索引

## 刮削功能使用

### 什么是刮削？

刮削是指从外部数据库（如 Bangumi、VNDB）获取游戏元数据的过程，包括：
- 游戏名称（中文/原名）
- 封面图片
- 游戏简介
- 开发商信息
- 发布日期
- 评分
- 标签/类型
- 角色信息

### 自动刮削

添加游戏后，系统可自动进行刮削：

1. 进入 **设置 > 刮削设置**
2. 开启 **添加时自动刮削** 选项
3. 设置 **匹配阈值**（默认 90%）
4. 当匹配度超过阈值时，系统自动应用元数据

### 手动刮削

1. 在游戏库或游戏详情页选择目标游戏
2. 点击 **刮削 (Scrape)** 按钮
3. 系统将从以下数据源搜索：
   - **Bangumi** (优先) - 中文数据最丰富
   - **VNDB** - 国际视觉小说数据库
   - **ymgal** - 中文 Galgame 数据库（待完善）
   - **cngal** - 中文 Galgame 数据库（待完善）

4. 搜索结果将显示匹配度百分比
5. 选择最匹配的结果
6. 点击 **应用 (Apply)** 确认

### 刮削结果展示

刮削成功后，游戏将显示以下信息：

| 信息类型 | 展示位置 |
|----------|----------|
| 封面图片 | 游戏卡片、详情页 |
| 中文名称 | 游戏列表显示 |
| 简介 | 详情页描述区域 |
| 评分 | 详情页评分显示 |
| 开发商 | 详情页信息栏 |
| 角色 | 详情页角色列表 |
| 标签 | 详情页标签区域 |

### 刮削数据源配置

在 **设置 > 刮削设置** 中可以：

- 开启/关闭各数据源
- 设置数据源优先级顺序
- 配置 Bangumi OAuth 登录（获取更完整数据）
- 设置匹配阈值

## 存档管理操作

### 存档位置自动检测

Galbox 支持多种引擎的存档位置自动检测：

| 引擎 | 存档位置 |
|------|----------|
| Ren'Py | `%APPDATA%/{GameName}/saves` 或 `game/saves` |
| Kirikiri | `savedata/` 目录 |
| TyranoBuilder | `data/save/` 目录 |
| Unity | `%UserProfile%/AppData/LocalLow/{Company}/{Game}` |
| RPG Maker MV | `www/save/` 目录 |
| RPG Maker VX Ace | 游戏目录 `.rvdata2` 文件 |

### 创建存档备份

1. 进入 **存档管理 (Save Manager)** 页面
2. 选择目标游戏
3. 点击 **创建备份 (Create Backup)** 按钮
4. 输入备份描述（可选）
5. 等待备份完成

**备份过程:**
- 系统自动检测存档位置
- 收集所有存档文件
- 创建 ZIP 压缩包
- 保存到备份存储路径

### 恢复存档备份

1. 在存档管理页面选择游戏
2. 查看备份列表
3. 选择要恢复的备份
4. 点击 **恢复 (Restore)** 按钮
5. 确认恢复操作

**注意:** 恢复前建议先创建当前存档的备份，以免丢失进度。

### 存档槽位切换

**快速切换功能**用于在不同剧情分支存档间快速切换：

1. 选择游戏
2. 点击 **快速切换 (Quick Switch)** 按钮
3. 选择目标存档槽位
4. 系统将：
   - 自动备份当前存档
   - 恢复目标存档

### 存档备份配置

在 **设置 > 存档设置** 中配置：

- **自动备份**: 游戏退出时自动备份
- **备份上限**: 每个游戏最大备份数（默认 10）
- **备份路径**: 自定义备份存储位置

## 补丁中心使用

### 补丁类型

Galbox 支持以下补丁类型：

| 类型 | 描述 |
|------|------|
| **汉化补丁** | 游戏中文翻译补丁 |
| **修复补丁** | 游戏问题修复补丁 |
| **18+补丁** | 成人内容解锁补丁 |
| **其他补丁** | 其他类型补丁 |

### 查询补丁

1. 进入 **补丁中心 (Patch Center)** 页面
2. 选择目标游戏
3. 系统将自动查询可用补丁
4. 显示补丁列表及详细信息

### 安装补丁

1. 选择要安装的补丁
2. 点击 **下载 (Download)** 按钮
3. 下载完成后点击 **安装 (Install)** 按钮
4. 按照安装指引完成操作

**安装状态:**

- 可用 - 补丁可下载
- 下载中 - 正在下载
- 已下载 - 等待安装
- 安装中 - 正在安装
- 已安装 - 安装完成
- 失败 - 安装失败

### 补丁管理

- 查看已安装补丁列表
- 卸载已安装补丁
- 更新补丁版本
- 查看补丁详情

## 特色功能

### 老板键 (Boss Key)

老板键功能让您可以快速隐藏游戏窗口，保护隐私。

#### 功能说明

按下设置的快捷键后，系统将：
1. 立即最小化所有游戏窗口
2. 可选：最小化到系统托盘
3. 可选：显示"正在工作"通知

#### 设置方法

1. 进入 **设置 > Boss Key 设置**
2. 开启 **启用 Boss Key** 选项
3. 设置快捷键组合（默认 `Alt+Shift+H`）
4. 配置隐藏行为：
   - **最小化到托盘** - 窗口隐藏到系统托盘图标
   - **显示通知** - 隐藏时显示伪装通知
   - **静音游戏** - 隐藏时自动静音

#### 使用技巧

- 选择不常用的快捷键组合，避免误触发
- 配合托盘图标，可快速恢复游戏窗口
- 支持设置多个快捷键组合

---

### 截图功能

Galbox 提供多种截图方式，帮助您记录游戏精彩瞬间。

#### 自动截图

游戏退出时自动截图，在 **设置 > 进程监控设置** 中配置：

| 设置项 | 说明 |
|--------|------|
| **自动截图** | 开启/关闭游戏退出时自动截图 |
| **截图格式** | PNG（无损）或 JPG（较小体积） |
| **JPG 质量** | JPG 格式的图片质量（1-100） |

#### 手动截图

游戏运行时，可通过以下方式截图：

1. **快捷键截图** - 使用系统截图快捷键（需先在设置中启用）
2. **Galbox 菜单** - 点击托盘图标，选择"截图"选项
3. **游戏内快捷键** - 部分游戏支持原生截图功能

#### 截图管理

所有截图保存在 `%LocalAppData%\Galbox\Screenshots\` 目录下：

- 按游戏名称自动分类存储
- 文件名包含游戏名和时间戳
- 支持在游戏详情页查看和管理

#### 截图操作

在游戏详情页的截图画廊中：
- **查看大图** - 点击缩略图打开预览
- **删除截图** - 右键菜单选择删除
- **打开目录** - 打开截图存储文件夹
- **复制到剪贴板** - 快速分享截图

### 错误检查功能

当游戏无法启动时，可使用错误检查功能自动诊断问题。

#### 使用方法

1. 在游戏详情页点击 **错误检查** 按钮
2. 系统将自动检测以下问题：

| 检查项目 | 说明 |
|----------|------|
| **路径检查** | 检测中文路径、特殊字符路径问题 |
| **文件完整性** | 检测游戏主程序是否存在 |
| **运行库** | 检测必需的 DirectX、VC++ 运行库 |
| **区域设置** | 检测是否需要日语区域设置 |
| **权限问题** | 检测是否需要管理员权限 |
| **进程冲突** | 检测是否有其他实例运行 |

3. 检查完成后显示问题列表和解决方案

#### 一键修复

部分问题支持一键修复：
- **缺失运行库** - 提供下载链接或自动安装
- **权限问题** - 提供以管理员身份启动选项
- **区域设置** - 自动配置 Locale Emulator（如已安装）

## 常见问题解答

### Q: 游戏无法启动怎么办？

**可能原因及解决方案:**

1. **中文路径问题**
   - 检查游戏安装路径是否包含中文
   - 移动游戏到纯英文路径目录

2. **日语区域设置**
   - 使用 Locale Emulator 或 NTLEA
   - 设置系统区域为日语（日本）

3. **DirectX 缺失**
   - 安装 DirectX End-User Runtime
   - 安装游戏自带 DirectX

4. **解码器缺失**
   - 安装 K-Lite Codec Pack
   - 确保视频播放组件完整

5. **运行库缺失**
   - 安装 Visual C++ Redistributable
   - 安装 .NET Framework

**使用错误检查功能:**

Galbox 提供 **错误检查 (Error Check)** 功能，自动检测并提示解决方案。

### Q: 刮削找不到匹配结果？

**解决方案:**

1. 尝试使用游戏原名（日语）搜索
2. 检查数据源是否启用
3. 手动搜索并选择最佳匹配
4. 使用 Bangumi/VNDB 网站手动查找 ID

### Q: 存档备份失败？

**可能原因:**

1. 存档位置未被正确检测
   - 手动指定存档路径
   - 检查游戏引擎类型

2. 权限问题
   - 以管理员权限运行 Galbox
   - 检查备份目录写入权限

3. 存档文件被占用
   - 关闭游戏后再备份
   - 检查其他进程是否占用

### Q: 补丁下载失败？

**解决方案:**

1. 检查网络连接
2. 检查补丁源是否可访问
3. 尝试手动下载并安装
4. 检查磁盘空间是否充足

### Q: 如何添加自定义存档路径？

当前版本暂不支持手动添加自定义存档路径，系统将根据引擎类型自动检测。后续版本将支持此功能。

### Q: 数据存储在哪里？

Galbox 数据存储位置：

```
%LocalAppData%\Galbox\
├── galbox.db          # SQLite 数据库
├── SaveBackups\       # 存档备份
└── Screenshots\       # 截图存储
```

### Q: 如何迁移数据到新电脑？

1. 复制 `%LocalAppData%\Galbox` 目录
2. 在新电脑放置到相同位置
3. 或在设置中配置自定义路径

### Q: Bangumi 登录有什么用？

Bangumi OAuth 登录可以：
- 获取更完整的游戏数据
- 提高 API 请求限额
- 同步收藏和评分数据

### Q: Boss Key 怎么设置？

默认 Boss Key 为 `Alt+Shift+H`，可在设置中自定义：
- 选择快捷键组合（Alt/Ctrl/Shift/Win）
- 设置触发按键
- 配置隐藏行为
