## 主界面介绍

Galbox 采用现代化的 WinUI 3 界面设计，主要分为以下几个区域：

### 导航栏

左侧导航栏包含以下主要模块：

| 模块 | 图标 | 功能 |
|------|------|------|
| **首页 (Home)** | 🏠 | 快速启动、最近游玩、收藏游戏 |
| **游戏库 (Library)** | 📚 | 所有游戏列表、搜索、筛选 |
| **存档管理 (Save Manager)** | 💾 | 存档备份、恢复、切换 |
| **补丁中心 (Patch Center)** | ⬇️ | 汉化补丁、修复补丁管理 |
| **设置 (Settings)** | ⚙️ | 应用配置、账户管理 |

### 首页布局

首页展示以下内容：

1. **快速启动卡片** - 显示最近游玩或收藏的游戏，一键启动
2. **正在游玩** - 最近 7 天内有游玩记录的游戏
3. **收藏游戏** - 用户标记为收藏的游戏
4. **最近游玩** - 按最后游玩时间排序的游戏列表

### 标题栏

- 显示应用名称 "Galbox"
- 支持 Mica 背景效果（跟随系统主题）
- 标题栏拖动可移动窗口

## 游戏添加流程

### 自动扫描添加

1. 进入 **游戏库 (Library)** 页面
2. 点击 **添加游戏 (Add Game)** 按钮
3. 选择 **扫描文件夹 (Scan Folder)** 选项
4. 选择包含游戏的根目录
5. 系统将自动扫描识别游戏可执行文件

**支持的自动识别引擎:**

- Ren'Py (`.rpy`, `python` 可执行文件)
- Kirikiri (`.xp3` 包文件)
- TyranoBuilder (`tyrano` 目录)
- Unity (`UnityPlayer.dll`, `_Data` 目录)
- RPG Maker (`rpg_core.js`, `.rvdata2`)
- 其他通用引擎

### 手动添加游戏

1. 在游戏库页面点击 **添加游戏**
2. 选择 **手动添加 (Manual Add)** 选项
3. 填写以下信息：
   - **游戏路径**: 游戏安装目录
   - **主可执行文件**: 启动游戏的主程序
   - **游戏名称**: 显示名称（可选，刮削后自动填充）

4. 点击 **确认 (Confirm)** 完成

### 批量添加

支持选择多个文件夹批量扫描添加游戏，系统会自动：
- 识别每个文件夹中的游戏
- 尝试自动刮削元数据（可配置）
- 建立游戏库索引

## 刮削功能使用

### 什么是刮削？

刮削是指从外部数据库（如 Bangumi、VNDB）获取游戏元数据的过程，包括：
- 游戏名称（中文/原名）
- 封面图片
- 游戏简介
- 开发商信息
- 发布日期
- 评分
- 标签/类型
- 角色信息

### 自动刮削

添加游戏后，系统可自动进行刮削：

1. 进入 **设置 > 刮削设置**
2. 开启 **添加时自动刮削** 选项
3. 设置 **匹配阈值**（默认 90%）
4. 当匹配度超过阈值时，系统自动应用元数据

### 手动刮削

1. 在游戏库或游戏详情页选择目标游戏
2. 点击 **刮削 (Scrape)** 按钮
3. 系统将从以下数据源搜索：
   - **Bangumi** (优先) - 中文数据最丰富
   - **VNDB** - 国际视觉小说数据库
   - **ymgal** - 中文 Galgame 数据库（待完善）
   - **cngal** - 中文 Galgame 数据库（待完善）

4. 搜索结果将显示匹配度百分比
5. 选择最匹配的结果
6. 点击 **应用 (Apply)** 确认

### 刮削结果展示

刮削成功后，游戏将显示以下信息：

| 信息类型 | 展示位置 |
|----------|----------|
| 封面图片 | 游戏卡片、详情页 |
| 中文名称 | 游戏列表显示 |
| 简介 | 详情页描述区域 |
| 评分 | 详情页评分显示 |
| 开发商 | 详情页信息栏 |
| 角色 | 详情页角色列表 |
| 标签 | 详情页标签区域 |

### 刮削数据源配置

在 **设置 > 刮削设置** 中可以：

- 开启/关闭各数据源
- 设置数据源优先级顺序
- 配置 Bangumi OAuth 登录（获取更完整数据）
- 设置匹配阈值

## 存档管理操作

### 存档位置自动检测

Galbox 支持多种引擎的存档位置自动检测：

| 引擎 | 存档位置 |
|------|----------|
| Ren'Py | `%APPDATA%/{GameName}/saves` 或 `game/saves` |
| Kirikiri | `savedata/` 目录 |
| TyranoBuilder | `data/save/` 目录 |
| Unity | `%UserProfile%/AppData/LocalLow/{Company}/{Game}` |
| RPG Maker MV | `www/save/` 目录 |
| RPG Maker VX Ace | 游戏目录 `.rvdata2` 文件 |

### 创建存档备份

1. 进入 **存档管理 (Save Manager)** 页面
2. 选择目标游戏
3. 点击 **创建备份 (Create Backup)** 按钮
4. 输入备份描述（可选）
5. 等待备份完成

**备份过程:**
- 系统自动检测存档位置
- 收集所有存档文件
- 创建 ZIP 压缩包
- 保存到备份存储路径

### 恢复存档备份

1. 在存档管理页面选择游戏
2. 查看备份列表
3. 选择要恢复的备份
4. 点击 **恢复 (Restore)** 按钮
5. 确认恢复操作

**注意:** 恢复前建议先创建当前存档的备份，以免丢失进度。

### 存档槽位切换

**快速切换功能**用于在不同剧情分支存档间快速切换：

1. 选择游戏
2. 点击 **快速切换 (Quick Switch)** 按钮
3. 选择目标存档槽位
4. 系统将：
   - 自动备份当前存档
   - 恢复目标存档

### 存档备份配置

在 **设置 > 存档设置** 中配置：

- **自动备份**: 游戏退出时自动备份
- **备份上限**: 每个游戏最大备份数（默认 10）
- **备份路径**: 自定义备份存储位置

## 补丁中心使用

### 补丁类型

Galbox 支持以下补丁类型：

| 类型 | 描述 |
|------|------|
| **汉化补丁** | 游戏中文翻译补丁 |
| **修复补丁** | 游戏问题修复补丁 |
| **18+补丁** | 成人内容解锁补丁 |
| **其他补丁** | 其他类型补丁 |

### 查询补丁

1. 进入 **补丁中心 (Patch Center)** 页面
2. 选择目标游戏
3. 系统将自动查询可用补丁
4. 显示补丁列表及详细信息

### 安装补丁

1. 选择要安装的补丁
2. 点击 **下载 (Download)** 按钮
3. 下载完成后点击 **安装 (Install)** 按钮
4. 按照安装指引完成操作

**安装状态:**

- 可用 - 补丁可下载
- 下载中 - 正在下载
- 已下载 - 等待安装
- 安装中 - 正在安装
- 已安装 - 安装完成
- 失败 - 安装失败

### 补丁管理

- 查看已安装补丁列表
- 卸载已安装补丁
- 更新补丁版本
- 查看补丁详情

## 常见问题解答

### Q: 游戏无法启动怎么办？

**可能原因及解决方案:**

1. **中文路径问题**
   - 检查游戏安装路径是否包含中文
   - 移动游戏到纯英文路径目录

2. **日语区域设置**
   - 使用 Locale Emulator 或 NTLEA
   - 设置系统区域为日语（日本）

3. **DirectX 缺失**
   - 安装 DirectX End-User Runtime
   - 安装游戏自带 DirectX

4. **解码器缺失**
   - 安装 K-Lite Codec Pack
   - 确保视频播放组件完整

5. **运行库缺失**
   - 安装 Visual C++ Redistributable
   - 安装 .NET Framework

**使用错误检查功能:**

Galbox 提供 **错误检查 (Error Check)** 功能，自动检测并提示解决方案。

### Q: 刮削找不到匹配结果？

**解决方案:**

1. 尝试使用游戏原名（日语）搜索
2. 检查数据源是否启用
3. 手动搜索并选择最佳匹配
4. 使用 Bangumi/VNDB 网站手动查找 ID

### Q: 存档备份失败？

**可能原因:**

1. 存档位置未被正确检测
   - 手动指定存档路径
   - 检查游戏引擎类型

2. 权限问题
   - 以管理员权限运行 Galbox
   - 检查备份目录写入权限

3. 存档文件被占用
   - 关闭游戏后再备份
   - 检查其他进程是否占用

### Q: 补丁下载失败？

**解决方案:**

1. 检查网络连接
2. 检查补丁源是否可访问
3. 尝试手动下载并安装
4. 检查磁盘空间是否充足

### Q: 如何添加自定义存档路径？

当前版本暂不支持手动添加自定义存档路径，系统将根据引擎类型自动检测。后续版本将支持此功能。

### Q: 数据存储在哪里？

Galbox 数据存储位置：

```
%LocalAppData%\Galbox\
├── galbox.db          # SQLite 数据库
├── SaveBackups\       # 存档备份
└── Screenshots\       # 截图存储
```

### Q: 如何迁移数据到新电脑？

1. 复制 `%LocalAppData%\Galbox` 目录
2. 在新电脑放置到相同位置
3. 或在设置中配置自定义路径

### Q: Bangumi 登录有什么用？

Bangumi OAuth 登录可以：
- 获取更完整的游戏数据
- 提高 API 请求限额
- 同步收藏和评分数据

### Q: Boss Key 怎么设置？

默认 Boss Key 为 `Alt+Shift+H`，可在设置中自定义：
- 选择快捷键组合（Alt/Ctrl/Shift/Win）
- 设置触发按键
- 配置隐藏行为
