# Galbox 产品知识提炼（来源：docs/USER_MANUAL.md + docs/README.md）

## 1. 软件定位与价值主张

| 项 | 内容 |
|---|---|
| 名称 | Galbox |
| 定位（手册） | "一款专为 Galgame（视觉小说）玩家设计的游戏管理工具" |
| 定位（README） | "一款专为 Galgame（视觉小说/美少女游戏）爱好者设计的 Windows 游戏管理平台"；"帮助玩家更好地组织和享受他们的游戏收藏" |
| 平台 | Windows（README 徽章：`platform-Windows`） |
| 许可 | "本项目采用 MIT 许可证开源。" |
| 版本 | README 徽章 `version-1.0.0-beta`（标注 `[待配置]`）；用户手册"文档版本: 1.1.0 \| 最后更新: 2026-04-14" |
| 收尾语 | "Made with love for Galgame enthusiasts." |
| 界面设计基调 | "Galbox 采用现代化的 WinUI 3 界面设计"；标题栏"支持 Mica 背景效果（跟随系统主题）" |

六大核心功能（手册原文列举）：
- "**游戏库管理** - 自动扫描、识别和管理多引擎 Galgame"
- "**元数据刮削** - 从 Bangumi、VNDB 等数据源获取游戏信息"
- "**存档管理** - 自动检测存档位置，支持备份、恢复和多版本管理"
- "**补丁中心** - 一键下载安装汉化补丁和修复补丁"
- "**快捷启动** - 快速启动游戏，支持老板键快速隐藏"
- "**截图管理** - 自动或手动截图，记录精彩瞬间"

README 的"特色功能"四条（可视为差异化卖点）：
- "**智能刮削匹配** - 基于 Levenshtein 距离算法，90%+ 匹配自动接受"
- "**多引擎存档识别** - 支持 Ren'Py、Kirikiri、TyranoBuilder、Unity、RPG Maker 等常见引擎"
- "**一键存档切换** - 快速切换不同存档槽位，方便体验不同剧情分支"
- "**系统兼容性检查** - 检测并提示常见运行问题，提供解决方案"

README 另列"错误检测""进程监控"为核心功能："**进程监控** - 实时监控游戏进程，Boss Key 快速隐藏，自动截图"。

## 4. 功能模块详解

### 4.1 游戏添加（三条路径）

**自动扫描添加**
1. 进入 **游戏库 (Library)** 页面
2. 点击 **添加游戏 (Add Game)** 按钮
3. 选择 **扫描文件夹 (Scan Folder)** 选项
4. 选择包含游戏的根目录
5. 系统将自动扫描识别游戏可执行文件

支持的自动识别引擎（识别特征）：Ren'Py（`.rpy`、`python` 可执行文件）、Kirikiri（`.xp3` 包文件）、TyranoBuilder（`tyrano` 目录）、Unity（`UnityPlayer.dll`、`_Data` 目录）、RPG Maker（`rpg_core.js`、`.rvdata2`）、"其他通用引擎"。

**手动添加**
1. 在游戏库页面点击 **添加游戏**
2. 选择 **手动添加 (Manual Add)** 选项
3. 填写：**游戏路径**（游戏安装目录）、**主可执行文件**（启动游戏的主程序）、**游戏名称**（"显示名称（可选，刮削后自动填充）"）
4. 点击 **确认 (Confirm)** 完成

**批量添加**：支持选择多个文件夹批量扫描添加，系统自动"识别每个文件夹中的游戏""尝试自动刮削元数据（可配置）""建立游戏库索引"。

### 4.2 刮削（元数据刮削）

定义（原文）："刮削是指从外部数据库（如 Bangumi、VNDB）获取游戏元数据的过程"，字段包括：游戏名称（中文/原名）、封面图片、游戏简介、开发商信息、发布日期、评分、标签/类型、角色信息。

**自动刮削启用步骤**
1. 进入 **设置 > 刮削设置**
2. 开启 **添加时自动刮削** 选项
3. 设置 **匹配阈值**（默认 90%）
4. "当匹配度超过阈值时，系统自动应用元数据"

**手动刮削步骤**
1. 在游戏库或游戏详情页选择目标游戏
2. 点击 **刮削 (Scrape)** 按钮
3. 系统从数据源搜索（优先级见第 8 节）
4. "搜索结果将显示匹配度百分比"
5. 选择最匹配的结果
6. 点击 **应用 (Apply)** 确认

**刮削结果落位**：封面图片 → 游戏卡片、详情页；中文名称 → 游戏列表显示；简介 → 详情页描述区域；评分 → 详情页评分显示；开发商 → 详情页信息栏；角色 → 详情页角色列表；标签 → 详情页标签区域。

**刮削设置可做的事**：开启/关闭各数据源、设置数据源优先级顺序、配置 Bangumi OAuth 登录（获取更完整数据）、设置匹配阈值。

### 4.3 存档管理（Save Manager）

**存档位置自动检测表**

| 引擎 | 存档位置 |
|---|---|
| Ren'Py | `%APPDATA%/{GameName}/saves` 或 `game/saves` |
| Kirikiri | `savedata/` 目录 |
| TyranoBuilder | `data/save/` 目录 |
| Unity | `%UserProfile%/AppData/LocalLow/{Company}/{Game}` |
| RPG Maker MV | `www/save/` 目录 |
| RPG Maker VX Ace | 游戏目录 `.rvdata2` 文件 |

**创建备份**：进入存档管理页面 → 选择目标游戏 → 点击 **创建备份 (Create Backup)** → 输入备份描述（可选）→ 等待完成。备份过程："系统自动检测存档位置""收集所有存档文件""创建 ZIP 压缩包""保存到备份存储路径"。

**恢复备份**：选择游戏 → 查看备份列表 → 选择要恢复的备份 → 点击 **恢复 (Restore)** → 确认恢复操作。注意原文："**注意:** 恢复前建议先创建当前存档的备份，以免丢失进度。"

**快速切换（Quick Switch）**：用于"在不同剧情分支存档间快速切换"。步骤：选择游戏 → 点击 **快速切换 (Quick Switch)** → 选择目标存档槽位 → 系统将"自动备份当前存档""恢复目标存档"。

**存档设置**：自动备份（"游戏退出时自动备份"）、备份上限（"每个游戏最大备份数（默认 10）"）、备份路径（自定义备份存储位置）。

### 4.4 补丁中心（Patch Center）

补丁类型四种：**汉化补丁**（"游戏中文翻译补丁"）、**修复补丁**（"游戏问题修复补丁"）、**18+补丁**（"成人内容解锁补丁"）、**其他补丁**。

查询流程：进入补丁中心页面 → 选择目标游戏 → "系统将自动查询可用补丁" → 显示补丁列表及详细信息。

安装流程：选择要安装的补丁 → 点击 **下载 (Download)** → 下载完成后点击 **安装 (Install)** → "按照安装指引完成操作"。

安装状态枚举（6 个）：**可用**（"补丁可下载"）、**下载中**、**已下载**（"等待安装"）、**安装中**、**已安装**、**失败**（"安装失败"）。

补丁管理能力：查看已安装补丁列表、卸载已安装补丁、更新补丁版本、查看补丁详情。

### 4.5 老板键 / Boss Key

- 原文："老板键功能让您可以快速隐藏游戏窗口，保护隐私。"
- 触发后行为（原文）："1. 立即最小化所有游戏窗口 2. 可选：最小化到系统托盘 3. 可选：显示\"正在工作\"通知"
- 设置：**启用 Boss Key**、**快捷键组合**（默认 `Alt+Shift+H`）、**最小化到托盘**（"窗口隐藏到系统托盘图标"）、**显示通知**（"隐藏时显示伪装通知"）、**静音游戏**（"隐藏时自动静音"）
- 使用技巧："选择不常用的快捷键组合，避免误触发""配合托盘图标，可快速恢复游戏窗口""支持设置多个快捷键组合"
- FAQ 补充："选择快捷键组合（Alt/Ctrl/Shift/Win）""设置触发按键""配置隐藏行为"

### 4.6 截图

- **自动截图**：在 **设置 > 进程监控设置** 配置；开关项为"开启/关闭游戏退出时自动截图"（触发时机＝游戏退出时）；**截图格式**：PNG（无损）或 JPG（较小体积）；**JPG 质量**：1-100
- **手动截图**三种方式："1. **快捷键截图** - 使用系统截图快捷键（需先在设置中启用） 2. **Galbox 菜单** - 点击托盘图标，选择\"截图\"选项 3. **游戏内快捷键** - 部分游戏支持原生截图功能"
- **存储**："所有截图保存在 `%LocalAppData%\Galbox\Screenshots\` 目录下"，"按游戏名称自动分类存储""文件名包含游戏名和时间戳""支持在游戏详情页查看和管理"
- **截图操作**（详情页截图画廊）：查看大图（点击缩略图打开预览）、删除截图（右键菜单选择删除）、打开目录、复制到剪贴板

### 4.7 错误检查（Error Check）

用途："当游戏无法启动时，可使用错误检查功能自动诊断问题。"

流程：游戏详情页点击 **错误检查** 按钮 → 自动检测 → "检查完成后显示问题列表和解决方案"。

检查项（6 项）：**路径检查**（"检测中文路径、特殊字符路径问题"）、**文件完整性**（"检测游戏主程序是否存在"）、**运行库**（"检测必需的 DirectX、VC++ 运行库"）、**区域设置**（"检测是否需要日语区域设置"）、**权限问题**（"检测是否需要管理员权限"）、**进程冲突**（"检测是否有其他实例运行"）。

**一键修复**（"部分问题支持一键修复"）：缺失运行库 →"提供下载链接或自动安装"；权限问题 →"提供以管理员身份启动选项"；区域设置 →"自动配置 Locale Emulator（如已安装）"。

### 4.8 进程监控
设置项：**高级监控**（"CPU/内存使用监控"）、**自动截图**（"游戏退出时自动截图"）、**监控间隔**（"监控刷新频率"）、**截图格式**、**JPG 质量**。

## 11. FAQ 透露的产品规则

游戏无法启动的可能原因与解决方案（原文要点）：
1. **中文路径问题** —— 检查路径是否含中文，移动游戏到纯英文路径目录
2. **日语区域设置** —— 使用 Locale Emulator 或 NTLEA；设置系统区域为日语（日本）
3. **DirectX 缺失** —— 安装 DirectX End-User Runtime / 游戏自带 DirectX
4. **解码器缺失** —— 安装 K-Lite Codec Pack，确保视频播放组件完整
5. **运行库缺失** —— 安装 Visual C++ Redistributable、.NET Framework
并引导使用 **错误检查 (Error Check)** 功能"自动检测并提示解决方案"。

其他规则：
- 存档备份失败时，建议"以管理员权限运行 Galbox""关闭游戏后再备份"
- 恢复备份前应先备份当前存档（防丢进度）
- 数据迁移靠复制 `%LocalAppData%\Galbox` 或"在设置中配置自定义路径"

## 13. 工作流程汇总（序号化）

**首次配置入门前置**：安装包安装 → （如遇依赖）安装 Windows App SDK Runtime → 启动 Galbox → 添加游戏 → 刮削元数据 → 管理存档 → 错误检查（README"快速开始"四步：添加游戏 / 刮削元数据 / 管理存档 / 检查错误）。

**添加游戏流程**：Library → Add Game → 扫描文件夹 或 手动添加 →（扫描）选根目录自动识别引擎与可执行文件／（手动）填路径+主程序+名称（可选）→ Confirm。

**刮削流程**：选游戏 → Scrape → 多源搜索（显示匹配度）→ 选结果 → Apply；（自动）设置开启"添加时自动刮削"+阈值 → 添加时匹配度超阈值自动应用。

**备份流程**：Save Manager → 选游戏 → Create Backup → 输入描述（可选）→ 自动检测存档位置 → 收集文件 → 打 ZIP → 存入备份路径 → 完成。

**恢复流程**：选游戏 → 看备份列表 → 选备份 → Restore → 确认（建议先备份当前存档）。

**快速切换流程**：选游戏 → Quick Switch → 选目标槽位 → 自动备份当前存档 → 恢复目标存档。

**补丁流程**：Patch Center → 选游戏 → 自动查询 → 选补丁 → Download → Install → 按安装指引完成。

**Boss Key 流程**：设置 > Boss Key 设置 → 启用 → 设快捷键（默认 `Alt+Shift+H`）→ 配置隐藏行为（最小化到托盘 / 显示通知 / 静音游戏）→ 游戏中按键即"最小化所有游戏窗口"。

**错误检查流程**：详情页 → 错误检查 → 六项检测 → 显示问题列表与解决方案 → 可一键修复（运行库/权限/区域设置）。
